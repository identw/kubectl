# kubectl

Minimal [Alpine](https://hub.docker.com/_/alpine)-based Docker images with `kubectl`.

Images are published to:

- `ghcr.io/identw/kubectl`
- `docker.io/identw/kubectl`

`latest` tracks the newest minor line below.
